1.这门课你们讲了什么
主要分四个方面讲的，信源、信源编码、信道、信道编码，信源编码有哈夫曼编码，算术编码，Shannon编码、shannon-fano编码等，为的是提高效率，用尽可能短的平均码长进行编码。信道涉及到信道容量的求解，学了……不同的信道。信道编码是为了纠错，提高准确度，增加冗余位纠错，学了两种常见的编码方式，但是常用线性分组码，比如说（7，4）汉明码

2.香农定理
R<C，R>H(U)，还有一个率失真的没学

3.信源编码和信道编码的作用，分别举例（非常重要，问到了4次）
信源编码体现有效性，信道编码体现可靠性。信源编码采用尽可能少的平均码长来提高传输效率，例如哈夫曼编码，让出现概率高的码字短，是最佳编码。信道编码通过增加冗余位来保证传输码字的正确性，常用汉明码。

4.哈夫曼编码为什么最佳
（不是很会）哈夫曼编码的思路是让概率最小的几个进行合并，直到最后合成一个，进行编码。是否是唯一可译码需要满足craft不等式，而哈夫曼编码是使craft不等式取等的编码方式，能体现出最佳（不确定）。换一个角度，哈夫曼编码C=I(X;Y)=H(U)，能取等

4.模拟信道有没有信道容量
波形信道可以用香农公式，部分模拟信道可以用香农公式，但直接说模拟信道……不知道

5.怎么求信道容量
信道容量是平均互信息的最大值，可以利用信道转移概率进行求解

6.怎么判断检错和纠错能力
最小汉明距离
