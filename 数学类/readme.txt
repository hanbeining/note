问到的问题，仅供参考，不一定对

1.独立和不相关的关系
独立一定不相关，不相关不一定独立。
从定义看，独立在概率、pdf、CDF上的体现都是两个变量联合的等于分别的相乘，不相关是相关系数等于0，相关系数的计算公式为两个变量的协方差除以二者标准差的乘积，独立时协方差等于0，所以独立一定不相关。而不相关只能说明一阶矩满足联合等于分别相乘，二阶矩等更高阶的无法判断，所以推不出独立。

2.联合概率和条件概率大小比较
从条件概率的定义来看，条件概率等于联合概率除以边缘概率，边缘概率小于等于1，所以条件概率大于联合概率
从韦恩图的角度看，联合概率是二者同时发生的概率，而条件概率是把样本空间缩小后二者同时发生的概率，显然条件概率大

3.判断函数凸性......还有吗
求二阶导和用定义

4.怎么求矩阵的逆......还有吗
初等行/列变换，利用伴随矩阵定义的公式，还有一些特殊的矩阵有特殊的方法

5.怎么判断方程组解的个数......还有吗
方阵可用行列式
普通的：系数矩阵和增广矩阵的秩是否相等，最高价非零子式（其实感觉就是秩）
